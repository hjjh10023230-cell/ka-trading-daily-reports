# KA Trading Daily Reports

KA 交易趋势日报中心，用于按交易日归档聚合、脱敏后的市场观察。

## 在线入口

- 报告中心：`https://hjjh10023230-cell.github.io/ka-trading-daily-reports/`
- 最新一期：`https://hjjh10023230-cell.github.io/ka-trading-daily-reports/latest.html`
- 历史日报：从报告中心进入，或访问对应日期目录

## 目录规则

```text
reports/<年份>/<YYYY-MM-DD>/index.html
```

## 每日更新

1. 原始 Excel 仅保存在仓库外，不得复制进仓库。
2. 生成并复核当日报告，按日期放入独立目录。
3. 更新 `reports.json`、首页卡片和 `latest.html`。
4. 发布前检查聚合口径、低样本披露与敏感信息。
5. 提交并推送到 `main`，GitHub Pages 自动更新。

## 固定四段式框架

1. 结论与本周主线；
2. 整体交易情绪与方向性成交资金，并补充分人群日均变化和贡献；
3. 标的轮动，并下钻各人群具体买入、卖出标的；
4. 单日交易趋势 × 本周热点事件 × 原运营计划/人群假设的交叉建议（保留、修改、删除等）。

新增分析只能嵌入整体情绪和标的轮动，不能替换或重排这四个主体部分。

日级行情与交易方向关系放入可折叠附录，仅作为判断参考，不作为主报告结构。

## 本地聚合

```powershell
python scripts/generate_report.py <仓库外Excel> --date YYYY-MM-DD `
  --trend <仓库外分人群趋势JSON> --output <仓库外聚合JSON>
```

- 生成器同时支持逐标的明细表，以及“人群 × 方向 × 品类 × 市场”（可选股票名称列）的双层表头透视表。
- 趋势 JSON 可选，但正式日报应提供；其 `reportDate` 必须与 `--date` 一致。
- 日均窗口默认使用截至报告日最近五个交易日，对比此前五个交易日。
- 透视表包含股票名称时，标的轮动必须下钻到各人群主要买入和卖出；没有逐标的字段时，只做市场/品类归因，不沿用历史日报的个股结论。
- 同一交易日若存在多个导出快照，正文采用最新逐标的文件，并在附录披露其与趋势表快照的总额差异。
- 交叉建议先读取周内既有策略与触达日历：已排期内容只判断继续、调整、降级或停止，正文优先展示相较昨日新增的证据，避免重复展开存量策略。
- 标的轮动可轻量补充 OpenD 当日日K涨跌、相对近5日均量和板块主题，用于辅助判断顺势参与、逆势承接、兑现或降风险；日股等无行情权限时明确标注，不做盘中时点推断。

## 口径说明

- `BUY 金额 − SELL 金额` 只是方向性成交金额差，不等于账户净入金或真实资金净流入。
- 未具备成交时间、持仓成本和账户现金变化时，只做日级行情关联，不判断具体盘中买卖点。
- 公开报告仅保留汇总、降精度信息，不上传 UID、账户、姓名、联系方式、内部链接、原始数据或可识别的单客户明细。
- `robots=noindex` 不能替代访问控制；本仓库内容仍属于公开信息。
